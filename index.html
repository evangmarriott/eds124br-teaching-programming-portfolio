Snap! · Sequencing

Drawing with a sequence

The sprite begins when the green flag is clicked, shares an opening message, and then follows a series of turns, movements, and pauses. Changing the order changes the path the sprite draws.

This small project makes sequence visible: each instruction contributes one part of the final outline.

02 / Learning in progress

What I’m
paying attention to.

This course is building my understanding of how programming ideas can be made clear to learners. I’m using small, visible programs to connect instructions with the behavior they produce.

Order mattersA sequence is a set of steps carried out in a particular order; changing that order can change the result.
Make behavior visiblePauses and simple actions make it easier to observe how each instruction affects the program.
Explain the codeDescribing the purpose of a program and how it works makes the thinking behind it explicit.
Build understandingSmall programs offer a concrete place to notice, test, and discuss computational ideas.
