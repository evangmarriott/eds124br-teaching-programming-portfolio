Programming project01

Drawing a house with a sequence

My first Snap! program uses an ordered set of turns, movements, and pauses to draw a house. The project helped me see how each instruction changes the sprite’s path and why the order of steps matters.

I also recorded a short explanation of the program’s purpose and how its code works.

03 / Learning in progress

Questions I’m
carrying forward.

As I work through the course, I’m collecting examples that make computational thinking visible and considering how to explain those ideas to learners. These notes will change as I encounter new concepts and try new approaches.

How does it work?Connect the instructions in a program to the behavior they produce.
How can I show it?Use examples and demonstrations to make abstract ideas easier to notice.
What can learners try?Look for ways to invite testing, making, and discussion.
What did I learn?Reflect on what changed in my understanding after each activity.
