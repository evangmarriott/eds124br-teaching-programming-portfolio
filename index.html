A house, built
with instructions.

My first Snap! program uses an ordered sequence of turns and moves to draw a house.

Snap! · Sequencing

Drawing with a sequence

The sprite starts when the green flag is clicked, shares an opening message, then follows turns, movements, and pauses. Changing the order changes the path it draws.

This project makes sequence visible: each instruction contributes a part of the outline.

02 / Learning in progress

What I’m
paying attention to.

I’m exploring how small, visible programs can connect instructions with the behavior they produce.

Order matters

A sequence follows a particular order; changing it can change the result.

Make behavior visible

Pauses help make each instruction easier to observe.

Explain the code

Describing the purpose and steps makes programming ideas explicit.

Build understanding

Small programs give learners something concrete to test and discuss.
